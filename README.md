# Jancher

Быстрый минималистичный лаунчер для Android с жестовым управлением.
Локальный, без аккаунтов, без облака, без телеметрии.

> Статус: ранняя разработка, но лаунчером уже можно пользоваться.

## Установка

Скачать APK из [релизов](https://github.com/0nigiris/Jancher/releases)
и открыть файл на телефоне. Дальше приложение обновляет себя само:
проверяет новые версии при открытии лаунчера и предлагает установить.

Требуется Android 12 или новее.

## Идея

Домашний экран — это не сетка иконок, а список того, чем пользуешься, плюс
поиск в одно движение. Группы приложений настраиваются целиком: состав,
порядок, вид, вложенность. Приложение может лежать в нескольких местах
одновременно, потому что «установленное приложение» и «место в лаунчере» —
разные сущности.

Подробности решений и архитектуры — в `docs/`:

## Сборка

Требуется JDK 21 и Android SDK (compileSdk 36, minSdk 31).

```
./gradlew :app:assembleDirectDebug
```

Два варианта сборки:

- `direct` — для прямой раздачи, умеет обновлять себя сам
- `play` — для Google Play: правила Play запрещают приложению обновляться
  в обход Play, поэтому в этой сборке механизма обновлений нет вовсе —
  вместе с разрешением на доступ в интернет

Порядок выпуска релиза описан в [UPDATES.md](UPDATES.md).
