# Jancher — зафиксированные решения

Документ фиксирует то, что уже решено. Всё остальное — предмет обсуждения.
Дата: 2026-08-23.

## Продукт

| Вопрос | Решение |
|---|---|
| Для кого | В первую очередь для владельца (Galaxy S23 Ultra, One UI). Публикация в Google Play — витрина, а не заказчик. Ради охвата качество кода и вида не снижаем. |
| Главный экран | Единый вертикальный список: верхняя зона (часы + виджеты) → Избранное → группы. Группы раскрываются на месте. Справа — рельс групп. |
| Наполнение групп | Правило + ручные правки. Правила: алфавитные диапазоны, категория Play, «всё остальное». Сортировка по частоте — опциональный переключатель. |
| Поиск | Свайп вверх снизу, поле и клавиатура сразу внизу. Источники: приложения, шорткаты, контакты, настройки, веб, вычисления. |
| Жесты у правого края | Рельс с отступом от края (системный «назад» не трогаем). Подгруппы — сдвиг влево от рельса тем же непрерывным движением. |
| Виджеты | Верхняя зона главного экрана рядом с часами, скроллится вместе со списком. |
| Dogfooding | Владелец ставит лаунчер по умолчанию сразу, как только тот умеет запускать приложения. |
| Обязательный итоговый набор | Виджеты, бейджи уведомлений, иконпаки, долгое нажатие → шорткаты. Всё это в roadmap, но не в первой сборке. |
| Процесс | Код пишет Claude, владелец направляет и ревьюит. |
| Визуальный стиль | На усмотрение Claude. Выбрано: типографика первична, динамическая палитра Material You как опция (см. 01-ARCHITECTURE). |

## Юридическое

| Вопрос | Решение |
|---|---|
| Лицензия кода | GPL-3.0-or-later |
| Имя и бренд | «Jancher» — торговая марка владельца, под лицензию не попадает. Форки обязаны переименовываться. Оформляется отдельным `TRADEMARK.md`. |
| Телеметрия | Нет. Ни аналитики, ни crash-репортов по умолчанию. |
| Сеть | **Пересмотрено 2026-09-29.** Сборка `play` — без доступа в интернет вообще. Сборка `direct` имеет `INTERNET` и `REQUEST_INSTALL_PACKAGES` ради самообновления: без них владельцу пришлось бы подключать телефон к компьютеру для каждой сборки. Веб-поиск по-прежнему передаётся в браузер через Intent, своих запросов приложение не делает. |

### Проверка имени (2026-08-23)

Поиск по реестрам торговых марок и GitHub совпадений на «Jancher» не дал: близкие марки — Jantzen, Janome, Janz, Jan Becher; на GitHub ближайшее — Jaunch (лаунчер JVM-программ, другой домен и написание). Совпадений в Google Play не найдено.

Что это значит и чего не значит:
- Имя выглядит свободным для использования и для регистрации.
- Веб-поиск **не заменяет** проверку по базам. Перед подачей в Play стоит прогнать имя по USPTO TESS (США), EUIPO (ЕС) и Роспатенту, если планируется регистрация.
- Google Play не запрещает похожие названия сам по себе, но снимает приложения по жалобе правообладателя. Регистрация марки — это защита, а не обязанность.
- Отдельно проверить занятость `applicationId` в Play перед первой публикацией: сменить его после релиза невозможно никогда.

## Технические базовые решения

| Параметр | Значение | Обоснование |
|---|---|---|
| Язык / UI | Kotlin + Jetpack Compose | Требование владельца, современный стандарт |
| minSdk | 31 (Android 12) | Все нужные API (Material You, monochrome-иконки, современный widget picker) уже есть на 31; ветвлений по сравнению с 33 не добавляется ни одного, а охват выше на ~20%. Единственное, что появляется на 33 — `AdaptiveIconDrawable.getMonochrome()`, и это одна проверка версии на весь проект. |
| targetSdk / compileSdk | Последний стабильный (36) | Требование Play |
| JDK для сборки | 21 | AGP не поддерживает установленные в системе JDK 25/26. Temurin 21 распакован в `~/.local/jdk/jdk-21.0.12.1+1` без root; системный `java` не тронут. |
| Форматы устройств | Только телефон, портрет | Планшет, ландшафт и складные — вне области MVP |
| Языки интерфейса | Английский + русский | Строки сразу через ресурсы, без хардкода |

## Фактическая конфигурация тулчейна (2026-08-24, фаза 0)

| Компонент | Версия | Примечание |
|---|---|---|
| Gradle | 9.7.1 | wrapper в репозитории |
| AGP | 9.3.2 | **Kotlin встроен в AGP 9**: плагин `org.jetbrains.kotlin.android` больше не применяется и вызывает ошибку сборки |
| Compose BOM | 2026.06.01 | 2026.08.00 требует compileSdk 37, а android-37 доступен только в preview-канале SDK — на preview-платформе релиз в Play не собрать |
| compileSdk / targetSdk / minSdk | 36 / 36 / 31 | |
| Android SDK | `~/Android/Sdk` | platforms 36, build-tools 36.0.0/36.1.0/37.0.0, cmdline-tools latest |

Сборка: `JAVA_HOME=~/.local/jdk/jdk-21.0.12.1+1 ./gradlew :app:assembleDebug`.

Размер релизного APK на каркасе: **1.3 МБ** (R8 full mode). Это опорная точка —
если после фазы 1 он вырастет непропорционально, значит в зависимости заехало
лишнее.

## Самообновление и два варианта сборки (2026-09-29)

| Параметр | Значение |
|---|---|
| Флейворы | `direct` (прямая раздача, умеет обновлять себя) и `play` (для Google Play, механизма нет вовсе) |
| Почему два | Правила Google Play прямо запрещают приложению обновлять себя в обход Play. Это не «выключенная настройка»: в play-сборке отсутствует и модуль `:core:updater`, и разрешение `INTERNET` — проверено на собранных APK. |
| Манифест обновления | `https://raw.githubusercontent.com/0nigiris/Jancher/master/update.json` |
| Частота проверки | При открытии лаунчера, но не чаще раза в 6 часов. Фоновой задачи нет: лаунчер открывают десятки раз в день, а постоянная проверка тратила бы батарею на то, что почти всегда не изменилось. |
| Целостность | SHA-256 считается в процессе загрузки и сверяется с манифестом. Дополнительно Android сам откажет в установке APK, подписанного другим ключом — это и есть защита от подмены, наш хеш ловит обрыв загрузки раньше. |
| Установка | `PackageInstaller`, без FileProvider и внешних активностей. Требует однократного разрешения «установка из этого источника» — приложение само отводит в нужный экран настроек. |
| Отзыв неудачной версии | Правкой `update.json` в ветке, без перевыкладывания APK. Порядок описан в `UPDATES.md`. |
